1. Elementary proof from the defining delay equation

Define omega(s)=1/s on [1,2], continuously, and for s>2 define
   (s omega(s))' = omega(s-1).
In particular omega(s)=(1+log(s-1))/s on [2,3].

First prove the global baseline omega(s)>=1/2 for s>=2.
On [2,3], H(s)=1+log(s-1)-s/2 is concave, H(2)=0,
and H(3)=log2-1/2>0. For example log2>=2/3 proves strict positivity
at3. Concavity gives H>=0 on the entire interval.
If the bound is proved through integer j>=3, then on [j,j+1]
   s omega(s)=j omega(j)+int_j^s omega(v-1)dv >=j/2+(s-j)/2=s/2.
This is induction, since v-1 lies in the already proved interval.

For completeness, the rational logarithm bound used here is
   log x >= 2(x-1)/(x+1) for every x>=1.
The difference is zero at1 and has derivative
   1/x-4/(x+1)^2 = (x-1)^2/[x(x+1)^2] >=0.
Thus log2>=2/3, without decimal approximations.

Now put q=7/3 and m=11/20. On [q,3], the same logarithm inequality gives
   omega(s) >= (3s-4)/s^2.
The cleared polynomial Q(s)=3s-4-m s^2 is concave. At both endpoints
it is nonnegative, since
   (3q-4)/q^2-m = 27/49-11/20 = 1/980 >0,
   (3*3-4)/3^2-m = 5/9-11/20 = 1/180 >0.
Concavity therefore proves omega>=m on [7/3,3].

On [3,10/3], use the already established global1/2 bound:
   s omega(s) >=1+log2+(s-3)/2 >=s/2+1/6.
Consequently omega(s)>=1/2+1/(6s)>=1/2+1/20=11/20.
The complete length-one seed interval [7/3,10/3] is now proved.
If omega>=m is known through q+j for an integer j>=1, then for
q+j<=s<=q+j+1,
   s omega(s)=(q+j)omega(q+j)+int_(q+j)^s omega(v-1)dv >=m s.
Here v-1>=q and v-1<=q+j, so the induction hypothesis applies.
This proves the bound on the whole half-line. Since
   7/3 < 12/5 < 5/2,
both requested/pilot ranges follow. There is no infinite numerical
iteration, inferred limiting value, or invocation of an unverified paper.
