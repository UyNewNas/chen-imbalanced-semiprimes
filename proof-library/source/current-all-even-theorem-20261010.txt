当前准哥德巴赫结论：定理、模块化证明与核查入口
2026-10-10。本文件汇总当前采用的证明；不替换打开的历史主稿。

一、准确结论

设
 C_2 = product_(ell>2 prime) (1-1/(ell-1)^2),
 C_N = C_2 product_(ell|N,ell>2) (ell-1)/(ell-2),
 H_N = C_N N/(log N)^2.
令 D_b(N) 计数不同的素数 p<N，满足
 N-p=q，或者 N-p=rq、r<=q^b，
其中 q 为素数，第二种情况的 r 也为素数。第一种情况等价于允许 r=1。
一个 p 只计一次；平方 q^2 在 b<1 时不属于 D_b。

当前定理为：对每个固定的 1/2<b<1，

 liminf_(N->infinity, 2|N) D_b(N)/H_N
     >= 1.96131568 - 6.7617368 log(1/b).                 (T)

特别地，存在 N_0，使每个偶数 N>=N_0 同时满足

 D_(0.74821909)(N) >= 10^(-5) H_N,
 D_(0.74821809)(N) >= 10^(-6) H_N,
 D_(0.9)(N)       >= 1.24889 H_N.                       (T1)

这是“每个充分大偶数”的结论，不是密度一或无限多个偶数的结论。
没有给出有效 N_0，也不主张覆盖尚未到达该阈值的整数。
证明使用下列经典定理和本项目写出的有限计算引理；不使用外部 Li
的 1.9728、Elliott--Halberstam 猜想、未经修复的无限制大剩余类
分布命题，或 OpenAI 论文集合中的未核实结论作为前提。

本文件是模块化数学证明的入口。具体解析推导、计算方法与完整运行
证据在下列被明确引用的模块中。JSON 的摘要和哈希只确定证据版本，
不代替数学论证。形式化与外部审稿状态不由本文件改变。

二、依赖方向与经典输入

证明依赖次序为

 经典输入 -> 局部中等变量估计 -> 实际系数的素数乘积分布 PP
         -> 同一上筛权的逐点不等式与密度 -> K
         -> 有限 H/h 动作和带配对裁剪的 Chen 权 -> c
         -> 有序坏半素数质量 -> (T).

实际系数的类别构造先于 PP 的应用，既不检查算术误差符号再选分解，
也不使用最终素数下界来证明自身的分布。数值积分只计算明确的解析
泛函。下筛表的正向 switching 成本先使用 K，因此上、下筛没有循环。

经典输入为：素数定理、Mertens、素数及 Mobius 的 Siegel--Walfisz、
Bombieri--Vinogradov、原始乘法大筛、固定阶除数均值、Shiu、Poisson、
完整 Kloosterman 和 Weil 界、维数一基本筛引理、普通 Rosser 正出口
级数及同一原始筛权的一侧界；另有 Maynard 的粗糙互素分组、指定
归一化的 Kuznetsov 和常规谱大筛、ABL 的互素算术参数移除与连续谱
版本、Kim--Sarnak 参数 7/32，以及 Pascadi 的 A/J 例外谱界。
这里只用同一 m 区间与同一加性相位；不声称任意逐层区间的 J 估计。

逐条对应原文的补充核查是
 final-classical-input-correspondence-20261010.txt。
这一对应说明使用了什么定理、其变量和系数条件如何满足，不把目标
分布结论自身改名为“经典输入”。

三、分布模块

distribution-medium-completion-20261010.txt 从精确互素均值出发，
在四项有固定余量的单项式尺度条件下证明因子化模数的有符号估计。
原稿中被忽略的大位移相位被完整保留；五坐标分部求和的 x^(5 kappa)
成本显式计入。Gevrey-2 主函数为 log^5 的 Poisson 截断提供足够尾界。
主项保留正 Gram 方差，并用带辅助互素过滤的均方界处理。

distribution-prime-product-completion-20261010.txt 给出光滑完整乘积
截断、确切三阶 HB 恒等式、实际粗糙 1/mu 系数的辅助 SW、几何 Fourier
分离、中等变量插入、低秩 BV，以及一个或两个长变量的直接 Brun 证明。
最后两个分支保留精确互素均值和双 Poisson 的两条零轴抵消；负的
Brun 下权不被错误地相乘。辅助筛秩增长的代价只进入有幂次余量的项。

distribution-coefficient-completion-20261010.txt 对当前上筛、下筛、
有限标记后代与正 switching 族构造同一实际系数的整盒分解。它保留
有色重数、完整及选定补集平方门槛、同一个小素数 beta，以及物理
密度层 lambda 与辅助分解层 ell_aux 的区别。辅助层不替换筛权。

上述三个模块合成如下 PP。对实际有限编译系数 rho_N 和所需光滑
素数乘积权 W_N，令 X_W^(q) 为其与 q 互素的精确质量，则

 sum_q rho_N(q) [sum_(m=N mod q) W_N(m)-X_W^(q)/phi(q)]
       = O_A(N/log(N)^A).                                (PP)

误差对所有充分大偶数 N 一致。原素数有固定正幂次下界，完整乘积
尺度与 N 接近；小完整乘积先用有幂次节省的绝对估计去除。PP 不被
扩张为任意高层 rho 或任意有符号尖锐耦合区域的定理。

四、上筛结论 U 已由构造得出

global-positive-upper-completion-20261010.txt 证明存在同一实际 rho_N，
满足

 R_N(n)=sum_(q|n)rho_N(q)>=rough_indicator(n)>=0,
 sum_q rho_N(q)/phi(q)<=(K+o(1)) C_N/log N,
 K=8452171/1250000=6.7617368,                             (U)

并且该 rho_N 正是 PP 中的系数。逐点不等式对负整数和零也成立。
普通原始筛密度由同一出口恒等式和目标均匀的 Euler 因子证明，
不是两个无关单侧筛估计的差。所有高阶收益通过同一因果树逐次相减；
87 个八阶域的同层重叠另外排除。编译误差与有限密度逼近各有预算。

完整数值引理 N 的上界公式只有四个基础项减去22项最终选用收益。
其原始上端 E 及每份预算 u 为

 E=9979702576710911234850619807816847864907359959 /
   1475913550962201227946780619099353215139840000,
 u=145007961227048312210593427530128000784681 /
   11807308407697609823574244952794825721118720000.

直接有理计算给出 K-E-2u > 9.6522*10^(-8)。有限参数先选定在这两份
正预算内，再令 N 增大，因此理想极限层不需要在有限筛权上精确达到。

若一个正素数乘积族的未筛质量满足
 limsup (log N) X_W/N<=J，
则 U 和 PP 推出其“余下 N-m 为素数”的计数至多 (KJ+o(1))H_N。
去掉互素均值限制时，先对模数求和：

 sum_(q:ell|q)|rho_N(q)|/phi(q) << log N/(ell-1).

每个原素数 ell>=N^a，所以更换均值只损失 O(X_W N^(-a)log N)，
没有错误的 N^Theta 乘子。用正外逼近处理尖锐几何区域，误差为绝对
误差，即使 J=0 也成立。每个固定精度均使用自身同一 rho_N。

七、从 U、C 得到最终因子限制

令 B_b(N) 计数 N-p=rq，q^b<r<=q 的坏半素数余数。唯一分解给出
精确等式 D_b=D12-B_b；平方属于坏项，素数余数属于好项。
在小完整乘积的可忽略尾部之外，两因子均有固定正幂次下界。
用 t=log r/log N，y=rq/N，有序未筛质量为

 J_b=int_0^1 dy int_(b/(1+b))^(1/2) dt/[t(1-t)]
     =log(1/b).

这里没有第二个排列因子。正外逼近与 U 得
 limsup B_b/H_N<=K log(1/b)，与 C 合成 (T)。
current-downstream-proof-spine-20261010.txt 给出这一扣除的完整细节，
包括互素均值、小素数余项、平方、单位、径向边界与全偶数量词。

根代理另用96项正 atanh 级数和有理余项计算三个对数。相对 (T1)
指定计数系数，严格剩余分别大于
 7.1260*10^(-8), 3.4146*10^(-8), 5.6040*10^(-6).
先将有限逼近误差取得比这些量更小，再令 N 充分大。C_N>=C_2>0，
故所有 O_A(N/log^A N)、A>2，和固定幂次节省都统一为 o(H_N)。
三个阈值取最大值即得 (T1)，不需要任何对 N 的平均。

八、与当前明确比较对象的关系

Li--Liu, arXiv:2606.05224v2, Theorem1.1 给同定义的 b=.9，计数
系数.0004；其后的备注给出可改为 b=.894。当前 b=.74821909 更小，
因此加强同一个“每个充分大偶数”的因子限制。不能只用新端点的
10^(-5) 与旧端点的.0004混比计数；在共同 b=.9 处，(T) 另给
1.24889，所以共同端点的计数比较也有单独依据。
原文：https://arxiv.org/html/2606.05224v2 ，Theorem1.1及紧随的备注。

这不是声称优于附加 WEH(.999) 假设下 b=.4 的条件结论，也不是把固定差
孪生素数命题或“几乎所有偶数”的两素数定理替代当前量词。已知
输入有缺口的1.9728派生线不作为已成立基准；本定理不恢复它。
文献核对支持上述具体比较，不构成对所有论文与全部变体的穷尽
优先权证明。此前未取得 Cai2008、Fouvry--Grupp1989完整原文的
事实仍在 current-frontier-comparison-20261010.txt 中明确保留。
